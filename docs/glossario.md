# Glossário

Termos próprios do projeto. Use estes em vez de nomes comerciais de outros CADs.

| Termo | Significado | Evitar (marca ou termo de terceiro) |
|---|---|---|
| Árvore de features | Lista ordenada das operações que constroem a peça | "FeatureManager" |
| Timeline | Visualização horizontal da árvore, com marcador de rollback | — |
| Marcador de rollback | Ponto da timeline após o qual as features ficam suprimidas | — |
| Corpo | Sólido independente dentro de uma peça | — |
| Esboço | Geometria 2D com restrições, base das features | — |
| Restrição | Relação geométrica ou dimensional imposta no esboço | — |
| Membro estrutural | Perfil varrido ao longo de um segmento do esqueleto | — |
| Esqueleto | Esboço 2D/3D que define os eixos dos membros estruturais | — |
| Lista de corte | Tabela de membros com comprimento, ângulos e quantidade | — |
| Junta | Relação cinemática entre componentes de montagem | "SmartMates" |
| Referência persistente | Identificação estável de face/aresta/vértice entre recomputes | — |
| HLR | Hidden Line Removal: cálculo das linhas visíveis/ocultas de uma vista | — |
| Malha | Superfície formada por triângulos (STL, OBJ, 3MF) | — |
| B-rep | Representação por fronteira: sólido descrito por faces, arestas e vértices exatos | — |
