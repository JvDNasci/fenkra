# Contextos

Material de referência trazido pelo usuário para orientar o desenvolvimento. Os textos foram
gerados com assistentes de IA a partir de descrições públicas dos sistemas comerciais; servem de
**ponto de partida**. O que vira requisito passa pelo [benchmark](../benchmark/) com fontes públicas
citadas.

| Arquivo | Tema | ID |
|---|---|---|
| [design-review.md](design-review.md) | 58 slides do design review (bugs, pedidos, filosofia de comandos, desenho, estrutural) + [imagens](review/) | `DR-01…DR-58` |
| [camera.md](camera.md) | Navegação de câmera: estilos de órbita e recentrar | `CTX-CAM` |
| [sketcher.md](sketcher.md) | Sketcher: geometrias, restrições, edição, solver, uso nos módulos | `CTX-SKT` |
| [superficies.md](superficies.md) | Wireframe e superfícies: comandos, modos, tolerâncias, continuidade | `CTX-SUP` |
| [estrutural.md](estrutural.md) | Estrutura Pai, montagem dinâmica, submontagens de solda | `CTX-EST` |
| [perfis-estruturais.csv](perfis-estruturais.csv) | Lista de perfis (ABNT, EN 10365, AISC). **Só designações: faltam as dimensões** | `CTX-PRF` |
| [engrenagens.md](engrenagens.md) | Gerador de engrenagens, chavetas e furos | `CTX-ENG` |
| [smart-fastener.md](smart-fastener.md) | Biblioteca de fixadores e preenchimento automático de furos | `CTX-FIX` |
| [fixadores.md](fixadores.md) | Lista de fixadores com normas | `CTX-FXL` |
| [hardwares.md](hardwares.md) | Fontes de dados para perfis e hardware mecânico (normas e catálogos) | `CTX-HW` |
| [plm-vpm.md](plm-vpm.md) | VPM/PLM: modelo de dados, API, sincronização, fases | `CTX-PLM` |

O arquivo original do review (`Contextos e deisgn review.pptx`) fica fora do repositório; o texto e as
imagens foram extraídos para cá (imagens reduzidas para JPEG).
