# Roteiro

## Regras de ouro

1. **O gancho vem antes de 1,5 s**, e é visual e falado ao mesmo tempo. Não comece com "oi, gente".
2. **Uma ideia por plano.** Se a frase tem "e" no meio, provavelmente são dois planos.
3. **Mostre o resultado antes do processo** (o bolo pronto, depois a receita).
4. **Laço aberto**: prometa algo cedo e entregue no fim ("o terceiro erro é o que mais custa").
5. **Texto na tela não repete a fala inteira**: reforça a palavra-chave.
6. **Escreva no tempo**: ~2,5 palavras por segundo de fala em português natural.

## Tipos de gancho

| Tipo | Exemplo de estrutura |
|---|---|
| Resultado | "Fiz X em Y tempo. Assim:" |
| Erro comum | "Você está fazendo X errado." |
| Pergunta direta | "Por que X sempre acontece?" |
| Contraste | "R$ 10 contra R$ 1.000: qual é melhor?" |
| Lista | "3 coisas que ninguém te conta sobre X" |
| Curiosidade visual | um plano estranho e sem explicação no primeiro segundo |
| Identificação | "Se você é X, para de rolar." |

Entregue sempre três ganchos de tipos diferentes.

## Estruturas

**Vertical de 15-60 s**

```
0-1,5 s   GANCHO (imagem + texto + fala)
1,5-5 s   CONTEXTO (por que importa)
5-45 s    ENTREGA em 3 batidas, cada uma com quebra de padrão
45-55 s   VIRADA ou recompensa do laço aberto
55-60 s   CHAMADA PARA AÇÃO ou volta ao início (loop)
```

**YouTube de 8-15 min**

```
0-30 s     GANCHO + promessa + prova (por que confiar)
30-60 s    mapa do vídeo (vira capítulos)
blocos     3 a 5 atos; cada um abre com uma minipergunta e fecha com um minigancho
meio       reengajamento por volta de 40-60% (revelação, mudança de cenário)
final      síntese + chamada para o próximo vídeo (não "é isso, tchau")
```

**Anúncio para cliente**: problema, agitação, solução (produto), prova, oferta, chamada para ação.

## Formato do roteiro

Use `modelos/roteiro.md`: tabela com tempo, fala, texto na tela, imagem e som. Acrescente sugestões
de título (YouTube: até 60 caracteres, palavra-chave no começo), legenda do post e capítulos.

## Revisão

Leia em voz alta e cronometre. Corte 20%. Marque toda frase que só funciona com som: o editor
precisa colocá-la na tela.
