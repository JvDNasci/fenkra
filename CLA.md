# Acordo de Licença de Contribuição do Fenkra (CLA)

Versão 1.0, de 13/11/2026.

Este acordo vale para tudo o que você envia ao Fenkra: código, dados da biblioteca, documentação,
ícones, imagens e textos. Ele existe para que o titular do projeto possa manter o núcleo livre e, no
futuro, oferecer também uma solução integrada sob outra licença sem precisar pedir licença a cada
contribuidor.

**Titular:** João Vitor Dias Nascimento, pessoa física. O acordo segue válido para quem suceder o
titular, inclusive uma empresa para a qual ele ceda os direitos do projeto.

> Este texto foi escrito pelo projeto, sem revisão de advogado. Se o titular mudar o acordo, a nova
> versão só vale para contribuições enviadas depois dela.

## 1. O que continua seu

O direito autoral sobre a sua contribuição continua sendo seu. Você pode usá-la como quiser, inclusive
em outros projetos.

## 2. O que você concede

Para cada contribuição que você enviar, você concede ao titular, de forma gratuita, mundial, não
exclusiva, perpétua e irrevogável, o direito de:

1. usar, copiar, modificar, publicar e distribuir a contribuição;
2. licenciar a contribuição a terceiros sob a licença do projeto (hoje LGPL-2.1-or-later) e também sob
   outras licenças, inclusive comerciais e fechadas;
3. transferir estes direitos a quem suceder o titular.

Se a contribuição usar uma patente sua, você concede também uma licença gratuita dessa patente, no
alcance necessário para usar e distribuir a contribuição como parte do Fenkra.

## 3. A promessa do projeto

Toda contribuição aceita continua disponível no repositório público sob uma licença de software livre.
Uma licença comercial dada a terceiros não retira os direitos de quem recebe o Fenkra como software livre.

## 4. O que você declara

- A contribuição é obra sua, ou você tem o direito de enviá-la nestes termos. Se ela foi feita no seu
  trabalho, seu empregador autorizou o envio ou não tem direitos sobre ela.
- Ela não copia código, texto, imagens ou ícones de software proprietário, nem traz conhecimento obtido
  sob confidencialidade (ver [CONTRIBUTING.md](CONTRIBUTING.md), seção 2).
- Partes de terceiros estão identificadas, com a licença e o aviso de copyright originais.
- Se parte relevante foi gerada por IA, você indicou isso no pull request.

## 5. Sem garantia

Você envia a contribuição como está, sem garantia de qualquer tipo, salvo o que declarou na seção 4.

## 6. Como aceitar

Inclua no primeiro pull request esta frase, com seu nome:

> Li e aceito o CLA do Fenkra, versão 1.0. — Seu nome

O aceite vale para todas as suas contribuições seguintes enquanto esta versão estiver em vigor.
